# 28 — Google Ads API Direct Read-Only Connector Bootstrap

**Roadmap ID:** PR-ADS-098  
**Phase:** 3 — Direct Google Ads Source Replacement  
**Status:** Bootstrap / Read-only  
**Blocks:** PR-ADS-099 Dataset Parity Audit  

---

## 1. Purpose

This document describes the bootstrap connector for reading Google Ads data
directly from the Google Ads API, replacing the Windsor.ai proxy over time.

**This PR is read-only.** No Google Ads mutations are performed.  
Windsor remains the active production source until PR-ADS-099 parity audit completes.

---

## 2. Credentials Required

The connector reads **exclusively from environment variables**. No secrets are
stored in the repository or in any config file committed to GitHub.

| Environment Variable | Required | Description |
|---|---|---|
| `GOOGLE_ADS_DEVELOPER_TOKEN` | ✅ Required | Developer token from Google Ads API Center |
| `GOOGLE_ADS_CLIENT_ID` | ✅ Required | OAuth 2.0 client ID from Google Cloud Console |
| `GOOGLE_ADS_CLIENT_SECRET` | ✅ Required | OAuth 2.0 client secret from Google Cloud Console |
| `GOOGLE_ADS_REFRESH_TOKEN` | ✅ Required | Long-lived OAuth refresh token (generated once, stored in Render) |
| `GOOGLE_ADS_CUSTOMER_ID` | ✅ Required | Customer (advertiser) account ID: `3059734490` |
| `GOOGLE_ADS_LOGIN_CUSTOMER_ID` | ⚙️ Optional | Manager account ID: `2020447570` — omit for direct customer mode |

### Manager Account ID vs Customer Account ID

- **Manager account** (`LOGIN_CUSTOMER_ID = 2020447570`): The MCC (My Client Center)
  account that owns the advertiser account. Used for `login_customer_id` in the API config.
- **Customer account** (`CUSTOMER_ID = 3059734490`): The advertiser account from which
  campaign data is actually read. Used in all GAQL queries.

## 2a. Access Modes

### Manager Mode

Use this when the Google Ads manager account is active and linked to the client account.

```
GOOGLE_ADS_LOGIN_CUSTOMER_ID=2020447570
GOOGLE_ADS_CUSTOMER_ID=3059734490
```

The connector includes `login_customer_id` in the API client config and logs:

```
Google Ads direct connector mode: manager
```

### Direct Customer Mode

Use this when the OAuth user has direct access to the actual Google Ads customer account,
or when the manager account is inactive/unlinked.

```
GOOGLE_ADS_LOGIN_CUSTOMER_ID=
GOOGLE_ADS_CUSTOMER_ID=3059734490
```

(Or simply leave `GOOGLE_ADS_LOGIN_CUSTOMER_ID` unset / delete the Render variable.)

The connector omits `login_customer_id` from the API client config and logs:

```
Google Ads direct connector mode: direct_customer
```

## 3. How to Generate the Refresh Token

Run this **once on your local machine**. Never run it in production or CI.

### Windows
```
set GOOGLE_ADS_CLIENT_SECRETS_FILE=C:\Users\Youssef\Secrets\google-ads-client-secret.json
python scripts/google_ads_generate_refresh_token.py
```

### Mac/Linux
```
export GOOGLE_ADS_CLIENT_SECRETS_FILE=/Users/youssef/secrets/google-ads-client-secret.json
python scripts/google_ads_generate_refresh_token.py
```

A browser window opens. Log in with `youssef.awwad@logistaas.com`.  
The script prints the refresh token.

**⚠️ Do NOT commit the refresh token to this repository.**  
**⚠️ Do NOT paste it in chat, email, or Slack.**  
**⚠️ Save it in Render only (see Section 4).**

## 4. How to Add Render Environment Variables

After generating the refresh token:

1. Go to **Render → Averroes service → Environment**
2. Add exactly these variables:

```
GOOGLE_ADS_DEVELOPER_TOKEN   = [from Google Ads API Center]
GOOGLE_ADS_CLIENT_ID         = [from OAuth client JSON]
GOOGLE_ADS_CLIENT_SECRET     = [from OAuth client JSON]
GOOGLE_ADS_REFRESH_TOKEN     = [generated by script]
GOOGLE_ADS_CUSTOMER_ID       = 3059734490
GOOGLE_ADS_LOGIN_CUSTOMER_ID = 2020447570   ← optional; leave empty for direct customer mode
```

Optional feature flags (keep `false`/`windsor` until parity audit passes):

```
GOOGLE_ADS_DIRECT_ENABLED = false
GOOGLE_ADS_DATA_SOURCE    = windsor
```

**No secrets go into GitHub.** All credentials live in Render environment only.

## 5. How to Run the Readiness Check

```
python scripts/google_ads_readiness_check.py
```

Expected output (all vars present, manager mode):
```
Google Ads API readiness
----------------------------------------
  GOOGLE_ADS_DEVELOPER_TOKEN: present  ****abcd
  GOOGLE_ADS_CLIENT_ID: present  ****abcd
  GOOGLE_ADS_CLIENT_SECRET: present  ****1234
  GOOGLE_ADS_REFRESH_TOKEN: present  ****5678
  GOOGLE_ADS_CUSTOMER_ID: present  3059734490
  GOOGLE_ADS_LOGIN_CUSTOMER_ID: present  2020447570 — manager mode

Status: READY
```

Expected output (direct customer mode — `GOOGLE_ADS_LOGIN_CUSTOMER_ID` absent):
```
Google Ads API readiness
----------------------------------------
  GOOGLE_ADS_DEVELOPER_TOKEN: present  ****abcd
  GOOGLE_ADS_CLIENT_ID: present  ****abcd
  GOOGLE_ADS_CLIENT_SECRET: present  ****1234
  GOOGLE_ADS_REFRESH_TOKEN: present  ****5678
  GOOGLE_ADS_CUSTOMER_ID: present  3059734490
  GOOGLE_ADS_LOGIN_CUSTOMER_ID: optional missing — direct_customer mode

Status: READY
```

Possible statuses:
- `READY` — all 5 required vars are present (`GOOGLE_ADS_LOGIN_CUSTOMER_ID` is optional)
- `PARTIAL` — some required vars are present
- `NOT_READY` — no vars are present

Use `--strict` flag to exit non-zero on incomplete config:
```
python scripts/google_ads_readiness_check.py --strict
```

## 6. How to Run the Smoke Test

Requires all env vars to be configured (see Section 4).

```
python scripts/google_ads_smoke_test.py
```

Expected output:
```
Google Ads direct API smoke test
========================================
Mode: direct_customer
Customer ID: 3059734490
Date range:  2026-06-01 → 2026-06-07

Client build: OK
Campaign rows: 123
Search term rows: 456
Keyword rows: 789

Status: PASS
```

The smoke test:
- Queries the last 7 days
- Prints row counts and up to 3 redacted sample rows
- Writes nothing to the database
- Does not mutate any Google Ads resource

## 6a. How to List Accessible Customers

Use this script to verify which Google Ads accounts the OAuth user can access.
Run it when the smoke test fails with `USER_PERMISSION_DENIED`.

```
python scripts/google_ads_list_accessible_customers.py
```

Expected output (direct customer mode):
```
Google Ads accessible customers
----------------------------------------
Mode: direct_customer
Accessible customers:
  - customers/3059734490
```

The script:
- Uses `CustomerService.list_accessible_customers()` (read-only)
- Writes nothing to the database
- Does not mutate any Google Ads resource
- Exits non-zero if no accessible customers are returned

## USER_PERMISSION_DENIED

If the smoke test fails with `USER_PERMISSION_DENIED`:

1. Run:
   ```
   python scripts/google_ads_list_accessible_customers.py
   ```

2. If `customers/3059734490` appears in the output:
   - Use direct customer mode by leaving `GOOGLE_ADS_LOGIN_CUSTOMER_ID` empty or unset in Render.
   - Redeploy, then re-run the smoke test.

3. If `customers/3059734490` does **not** appear:
   - Grant the OAuth Google user (the Google user used to generate the refresh token) access to account `305-973-4490` in Google Ads.
   - Ensure this is a Google Ads user with access to the target customer account.
   - Regenerate the refresh token using `scripts/google_ads_generate_refresh_token.py`.
   - Update `GOOGLE_ADS_REFRESH_TOKEN` in Render and redeploy.

## 7. Explorer Access Limitations

This connector uses **Google Ads API Explorer Access**, which is sufficient for
production account reads with the following limitations:

- **15,000 operations/day** (vs 1,000,000 for Basic/Standard)
- No access to some advanced reporting segments
- Sufficient for: campaign, search term, keyword, and geo reads

If daily operation limits become a constraint, apply for **Basic Access** via
the Google Ads API Console.

---

## 8. No-Write Safety Rules

This connector is strictly read-only. The following services and operations are
**never used** in `connectors/google_ads_direct.py`:

| Prohibited service / operation | Reason |
|---|---|
| `mutate` | Writes data to Google Ads |
| `CampaignBudgetService` | Changes campaign budgets |
| `ConversionUploadService` | Uploads offline conversions |
| `OfflineUserDataJobService` | Uploads user data |
| `CustomerNegativeCriterionService` | Adds negative criteria |
| `AdGroupCriterionService` (mutate) | Modifies ad group keywords |

Only `GoogleAdsService.SearchStream` and `GoogleAdsService.Search` are used.
